# AISL Attribute Lineage Explorer — установка и локальный запуск

## Начните здесь: на своём компьютере, без инфраструктуры банка

**Для текущей демонстрации никакой внутренний веб-сервер банка не требуется.** Вы самостоятельно запускаете маленький локальный HTTP-сервер на своём компьютере. Он доступен только по `127.0.0.1` (только с этой машины). Данные в комплекте синтетические.

### 1. Что потребуется

- Windows, macOS или Linux и современный браузер с поддержкой JavaScript-модулей.
- Python 3.9 или новее **на компьютере, где запускается локальный сервер**. Устанавливать его нужно только при отсутствии; в состав приложения сторонние Python-пакеты не входят.
- Ни Docker, ни Nginx, ни Apache, ни Node.js, ни Elasticsearch для демонстрации не нужны.

### 2. Распакуйте ZIP и запустите сервер

Распакуйте **всё содержимое** архива в отдельный каталог, например `aisl-explorer`. В каталоге должны оказаться `index.html`, `start_local.py`, `app.mjs`, `graph-core.mjs`, `styles.css` и папка `demo/`.

**Windows:** откройте этот каталог в Проводнике, в адресной строке введите `cmd`, нажмите Enter и выполните:

```bat
py -3 start_local.py
```

Если команда `py` отсутствует, но Python установлен, попробуйте `python start_local.py`.

**macOS / Linux:** откройте Терминал, перейдите в распакованный каталог и выполните:

```bash
python3 start_local.py
```

Скрипт выведет адрес **`http://127.0.0.1:8080/`** и попробует открыть браузер. Если вкладка не открылась, введите этот адрес самостоятельно. Сервер работает только пока открыто окно терминала.

**Остановить:** нажмите `Ctrl+C` в том же окне терминала. Если порт 8080 занят, используйте `py -3 start_local.py --port 0` (Windows) или `python3 start_local.py --port 0` (macOS/Linux): будет выбран свободный порт, адрес напечатается в терминале.

**Важно:** не открывайте `index.html` двойным щелчком как `file://`: браузеры ограничивают загрузку JS-модулей. Используйте `http://127.0.0.1:8080/` (или адрес, выведенный скриптом). Для текущего локального сценария `https://` и домен банка не нужны.

### 3. Что вы увидите

Встроенный синтетический пример: 3 взаимодействия, 15 маршрутов, 86 узлов и 77 связей. Переключайтесь между **«Обзор систем»**, **«Поток атрибутов»** и **«Паутина»**. Выбор узла в «Паутине» выделяет входящие и исходящие ветви. Пунктирные `candidate` — не подтверждённые пересечения.

Кнопка **«Загрузить JSON»** открывает JSON с вашего компьютера. Можно выбрать `demo/lineage.json` или `demo/lineage-all-edges.json`. Содержимое остаётся в памяти браузера и не пересылается на сервер или в интернет.

### 4. Если не получается

- **`py` / `python3` не найдена:** проверьте наличие установленного Python (`py -3 --version`, `python3 --version`). Только компьютер, выполняющий роль локального сервера, нуждается в Python.
- **Порт занят:** используйте `--port 0`; открывайте **именно** адрес, который напечатает скрипт.
- **Пустая страница или ошибка загрузки модулей:** проверьте, что открываете URL с `http://127.0.0.1`, а не `file://`, и что все файлы ZIP распакованы.
- **Запрещён запуск локального сервера политикой устройства:** это ограничение устройства; обходить корпоративные правила безопасности нельзя. Локальную проверку надо выполнять на машине, где такой запуск разрешён.

## Впоследствии: размещение на банковском веб-сервере (не требуется сейчас)

Если позже будет выделен согласованный банком внутренний статический HTTP(S)-сервер, администратор сможет разместить только браузерные файлы и папку `demo/` без `start_local.py`. Здесь **не предполагается, что такой сервер уже есть**. Он не входит в нынешнюю демонстрационную поставку и не нужен для испытания на одном компьютере. Для банковской эксплуатации отдельно потребуются одобрение безопасности и проверка корпоративного браузера.

## Проверка целостности

Файл `SHA256SUMS.json` содержит SHA-256 и размер каждого файла архива, кроме самого манифеста. Сборка воспроизводимая: одинаковые исходники дают побайтово одинаковый ZIP.

## Для разработчика: пересборка приложения

Только при наличии **исходников репозитория** `aisl-application` (сам этот ZIP — уже готовая поставка):

```bash
python3 attribute-lineage-explorer/tools/build_clean_delivery.py --output /tmp/aisl-attribute-lineage-explorer.zip
```

Для проверки исходников на машине с Node.js 20+: `node tests/test-core.mjs`, `node tests/test-web.mjs`; для проверки сборщика: `python3 tests/test-clean-delivery.py`. Эти инструменты не требуются для использования готового интерфейса в браузере.

## Ограничения и безопасность

- Только read-only просмотр JSON, без доступа к GitHub/Nexus/AISL API. Данные примеров синтетические.
- Автономные CSS/JS/JSON, нет CDN, платных библиотек, Elasticsearch, телеметрии, внешних runtime-запросов.
- Нет приложения для установки и отдельной БД. Для локального **хостинга** нужен только Python на этой машине; после будущего размещения на сервере пользователям нужен лишь браузер.
- Сервер привязан к `127.0.0.1`, не доступен с других компьютеров, отправляет CSP и защитные HTTP-заголовки. Загружаемые JSON не сохраняются.
